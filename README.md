# DGX Spark Development Workflow

A practical setup for using DGX Spark as your daily AI development workstation: VS Code Remote SSH, container-first dev with NGC images, Python and PyTorch on ARM64 (with the wheel-availability reality of 2026), JupyterHub for small teams, fine-tuning at scale within 128 GB unified (full BF16 / LoRA / QLoRA / NeMo SFT), dataset storage and streaming, the HF→MX-FP4→NIM quantisation pipeline, custom Triton kernels, and the local-iteration + cloud-burst workflow. Includes an interactive task-to-workflow picker.

**Live site:** https://brendanjameslynskey.github.io/NVIDIA_GPU_36_DGX_Spark_DevWorkflow/
